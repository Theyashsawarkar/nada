Changelog

Every change to nada, newest first. Releases are git tags (all tags, GitHub releases); the source of this page is CHANGELOG.md.

v0.1.32026-10-24release ↗

  • Background failures are reported again. Every failed background job (lyrics, cover art, a YouTube lookup) crashed its own error handler with NameError: cannot access free variable 'e': the callback ran after Python had unbound the exception. So "no lyrics", the art-less notification and the error toast never showed, and the real error was lost.
  • Logs go to the journal. nada starts the player as your nada.service if you have one, else as a transient unit (systemd-run): journalctl --user -u nada -u nada-daemon. Only without systemd does it write ~/.local/state/nada/daemon.log, now kept under 1 MB (it grew forever). An exception nobody caught, in a GTK callback or a thread, is logged with its traceback; NADA_DEBUG=1 adds debug messages.
  • Undo/redo keep the last 200 changes (they grew without limit).
  • The README, CONTRIBUTING and the bug report form point to the journal.

v0.1.22026-10-21release ↗

  • Follows your theme: with varna installed, nāda takes the current theme's colours (its own pick under tools.nada, else the desktop's), accent included, and restyles the moment the theme changes, while it plays. Without varna, nothing changes.
  • Placeholder covers use the theme's colours too.

v0.1.12026-10-21release ↗

  • A website (GitHub Pages, https://theyashsawarkar.github.io/nada/): the README as a home page, the changelog, and architecture decision records (docs/adr/), built from these files by scripts/build-site.py; CI checks the site is up to date.
  • Waybar module: the bars in the accent colour; a pause sign (not flat bars) while paused.

v0.1.02026-10-21release ↗

First release.

  • Home: the playing song's lyrics, large, synced and centred on the line being sung (click a line to jump there); the cover, title, singers, film or album, views and release age, and the next three songs on the right.
  • Queue with played / now playing / added by you / autoplay sections; every row shows views and how long ago the song came out. Vim editing (dd, J/K, yy/p, V, u, Ctrl+r), drag to reorder, × to remove.
  • Autoplay like YouTube: a YouTube song's own mix, or the rest of a local song's album and its artist; refills as the queue runs low; M toggles it.
  • YouTube search (yt-dlp, no account) with views and age on each result; stream links are renewed before they expire, and a failed stream is renewed and retried.
  • Downloads (D): Opus (no re-encoding) into ~/Music/YouTube/<Artist>/<Title>.opus with tags, cover and a .lrc; the queue entry becomes the file in place, playback carries on.
  • Lyrics from a .lrc, the file's tags or LRCLIB, with YouTube titles cleaned up first; :lyrics <search> to pick by hand.
  • Library in columns (artists, albums, genres, folders), playlists mixing files and YouTube (:w, :e), a mini player (z), vim commands (:sleep, :seek, :vol, :yt, :play…).
  • Desktop: MPRIS (media keys, playerctl, KDE Connect), nada ctl, nada status, nada waybar, song-change notifications.
