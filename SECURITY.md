# Security policy

## Supported versions

Only the latest release of nāda gets fixes.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through
[GitHub's security advisories](https://github.com/Theyashsawarkar/nāda/security/advisories/new),
with what an attacker could do and how to reproduce it. You'll get a reply
within a week; a fix and a release follow as soon as it's confirmed, with
credit to you unless you'd rather not.

nāda runs as your user. It runs yt-dlp and talks to MPD, LRCLIB and YouTube; it never
sends anything about you anywhere else.
